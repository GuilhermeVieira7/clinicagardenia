# Clínica Dra. Gardênia Monteiro

Site institucional da clínica (Parauapebas, PA): tratamentos e valores, antes e depois de rinomodelação, como funciona, perguntas frequentes e localização. Todos os botões de agendamento abrem o WhatsApp (94) 98136-8441 com mensagem pronta.

Site estático (HTML, CSS e JS puros), sem etapa de build. Para publicar na Vercel: importe este repositório, mantenha o preset "Other" e clique em Deploy.

- `index.html`: conteúdo e textos (preços ficam aqui)
- `styles.css`: visual
- `script.js`: abas, comparador antes/depois e links do WhatsApp
- `assets/`: logotipo e fotos de resultados
